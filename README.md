# Hospital Management System - Spring Boot

A web-based Hospital Management System built with Spring Boot, JPA, and H2 Database.

## Features
- Patient Registration & Management
- Doctor Management
- Appointment Scheduling
- Billing System

## Tech Stack
- Java 17, Spring Boot 3, Spring Data JPA
- H2 Database, Maven
- HTML, Thymeleaf

## How to Run
mvn spring-boot:run
Then open http://localhost:8080
